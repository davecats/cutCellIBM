# Raw results of the second-order study (2026-09-10)

Compact records of the runs behind `doc/secondOrderStudy.md` and Section 7/10 of
`doc/cutCellIBM.tex`; the full case directories (about 300 MB of fields) were not kept and are
regenerated by the scripts named in each file.

- `orderTest.txt`: last `orderTest` line of every `ibmOrderTest` run of
  `tutorials/order/laplaceDisk/Allrun` (problems LD, LN, CD, CN; switch off/on; N = 20...160).
- `taylorCouette.txt`: output of `validation/taylorCouette_error.py` for
  `tutorials/order/taylorCouette` at N = 40, 80, 160 with the switch off and on.
- `forces_tc_*.dat`: `postProcessing/ibmForces/.../forces.dat` of those runs.
- `richardson.txt`: iterations, convergence flag and final `IBM force` line of the
  `validation/richardson_drag.sh` runs (N = 41, 81, 161, 321).
- `taylorCouette_linked.txt`: output of `validation/taylorCouette_cellError.py` (error by cell
  class: all, cut, bulk, wall gradient) for the linking sweep (mergeAlpha 0 / 0.5, N = 40...320)
  before and after the group-centroid change of 2026-11-02, and radial error profiles
  (`doc/iddesPlan.md` section 10).
  The last blocks: the same after the second-order continuity flux of 2026-11-02, the pressure
  error profiles before and after it (`validation/taylorCouette_pressureError.py`), and the
  parallel check (`doc/secondOrderStudy.md`, "Fix of 2026-11-02").
- `orderTest_linked.txt`: `ibmOrderTest` (which now links cells when mergeAlpha > 0) for LD, LN,
  CD with mergeAlpha 0 and 0.5, N = 20...320.
- `richardson.txt`, last block: the drag runs after the continuity-flux fix (α_min 0.02) and the
  runs without sliver absorption (α_min 0.002).
