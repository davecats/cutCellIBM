# Raw results of the second-order study (2026-09-10)

Compact records of the runs behind `doc/secondOrderStudy.md` and Section 7/10 of
`doc/cutCellIBM.tex`; the full case directories (about 300 MB of fields) were not kept and are
regenerated by the scripts named in each file.

- `orderTest.txt`: last `orderTest` line of every `ibmOrderTest` run of
  `tutorials/order/laplaceDisk/Allrun` (problems LD, LN, CD, CN; switch off/on; N = 20...160).
- `taylorCouette.txt`: output of `validation/taylorCouette_error.py` for
  `tutorials/order/taylorCouette` at N = 40, 80, 160 with the switch off and on.
- `forces_tc_*.dat`: `postProcessing/ibmForces/.../forces.dat` of those runs.
- `richardson.txt`: iterations, convergence flag and final `IBM force` line of the
  `validation/richardson_drag.sh` runs (N = 41, 81, 161, 321).
