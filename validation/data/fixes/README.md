# Raw results of the rotating-wall source fix (2026-09-29)

Records of the runs behind the section "Rotating bodies" of `doc/cutCellIBM.tex` (the fix of
issue 1 of `doc/openIssues/openIssues.pdf`, in the open-face form). The case directories were
not kept; they are regenerated by the tutorials named below.

- `taylorCouette.txt`: `validation/taylorCouette_error.py` on `tutorials/taylorCouette` at
  N = 40, 80, 160 with the point-evaluated source (before), the source of the handout with the
  area-weighted handover of removed cells (rejected), and the open-face source (after), with
  the last mass-source line of each run.
- `rotation.txt`: mass-source diagnostics of `tutorials/rotatingCylinder` (before and after)
  and of `tutorials/eccentricRotation` (every step, serial and on four ranks).

The runs were made with `movingBody`; the moving-body code of `scalar` is the same, and the
translating cases are byte-identical before and after the change on both branches.
